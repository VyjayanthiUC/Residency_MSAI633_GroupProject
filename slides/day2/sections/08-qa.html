GLM 5.3 Flash: fast, cheap, and the model we proposed

1.65 smedian time to write an answer
$0.15per million input tokens, list price ($0.50 output)
1model for every configuration, including “from memory”

Report 00 (proposal, model choice); report 06 §1 and §4 (B3 generation p50; OpenRouter list price for z-ai/glm-5.3-flash).

Deep: we chose it in the proposal for speed and price, and kept it. Using one model everywhere means every difference between configurations comes from retrieval, not from the model. A bigger model might write better answers; most of our errors are retrieval misses, so that is not where we would spend first.
